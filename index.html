Interactive WebGL Fluid Canvas

The animated background on this very page — a real-time Navier–Stokes fluid solver written in GLSL, running entirely in fragment shaders. Move your cursor across the site to stir it up. Falls back to a CSS gradient on devices without WebGL.

Y2K Aesthetic Lab

An ongoing series of experiments reviving early-2000s personal-site conventions — dropdown music players, marquee tickers, glitter cursors — rebuilt with modern CSS and JS instead of Flash and table layouts.

Procedural Web Audio Synth

A tiny synthesizer built on the Web Audio API that generates the "Synthwave" and "Chiptune" tracks in the music widget live, with no audio files at all — just oscillators and gain envelopes.
